# Pokedex Web Application

A responsive Pokedex web application built using vanilla JavaScript that displays Pokémon data fetched from the PokeAPI. This project is developed for learning and entertainment purposes.

## Purpose

This application is intended for entertainment and educational use.  
All Pokémon data is provided by the public PokeAPI.

## Features

* Browse and view Pokémon
* Search Pokémon by name or ID
* Add and remove Pokémon from favorites (saved using Local Storage)
* Detailed Pokémon pages with:
  * Stats
  * Abilities
  * Types
  * Descriptions
* Dynamic UI styling based on Pokémon type
* Next / Previous navigation between Pokémon
* Responsive design for different screen sizes

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* [PokeAPI](https://pokeapi.co/)
* Browser Local Storage

## Project Structure

* `index.html` — Main Pokémon list page
* `detail.html` — Individual Pokémon detail page
* `pokemon.js` — Main list functionality
* `pokemon-detail.js` — Detail page functionality
* `search.js` — Search and filter functionality
* `style.css` — All styling
